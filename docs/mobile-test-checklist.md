# 실기기 수동 검증 체크리스트

Playwright(Chromium + Pixel 7 에뮬레이션)로 자동 검증한 항목과 별개로, **HTTPS 배포 URL**에서 실제 휴대폰으로 확인해야 합니다. 아직 실기기 검증 전입니다.

| # | 항목 | Android Chrome | iOS Safari |
|---|---|---|---|
| 1 | 배포 URL 접속 → 서가 표시 | ☐ | ☐ |
| 2 | 설치(설정 탭 버튼 / 공유 → 홈 화면에 추가) → 독립 실행 창(주소창 없음) | ☐ | ☐ |
| 3 | 설치된 앱에서 책 1권 *오프라인 저장* → *오프라인 저장됨* | ☐ | ☐ |
| 4 | 앱 완전 종료 → 비행기 모드 → 앱 실행 → 서가·검색 | ☐ | ☐ |
| 5 | 비행기 모드에서 저장한 책 열기, 원본 버튼(탭/다크모드/아코디언) | ☐ | ☐ |
| 6 | 비행기 모드에서 코드 복사 → 다른 앱에 붙여넣기 | ☐ | ☐ |
| 7 | 비행기 모드에서 미저장 책 → 안내 화면 | ☐ | ☐ |
| 8 | 목차 드로어: 바깥 탭/뒤로가기 제스처로 닫힘 | ☐ | ☐ |
| 9 | 스크롤 후 앱 종료 → 재실행 → 이어 읽기 위치 복원 | ☐ | ☐ |
| 10 | 긴 코드 블록·넓은 표 가로 스크롤 (iframe 안) | ☐ | ☐ |
| 11 | 노치/홈 인디케이터 영역에 UI 가림 없음 | ☐ | ☐ |
| 12 | Safari에서 저장한 책이 홈 화면 앱에서도 보이는지(분리 여부 기록) | — | ☐ |
| 13 | 새 버전 배포 후 *업데이트 준비 완료* → 적용 → 북마크·진행률 유지 | ☐ | ☐ |
| 14 | JSON 백업 파일 저장 → 복원 | ☐ | ☐ |

iOS 참고: iframe 내부 스크롤·`100dvh`·`<dialog>`는 iOS 15.4+ 기준. 그 이하 버전은 미지원.
